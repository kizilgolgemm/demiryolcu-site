DEMIRYOLCU.COM.TR - Tren Animasyonlu Premium Bakım Sayfası

GitHub Pages için hazır dosya paketi.

Yüklenecek dosyalar:
- index.html
- 404.html
- logo.png
- favicon.ico
- icon-192.png
- icon-512.png
- site.webmanifest
- CNAME

Kurulum:
1) Bu ZIP dosyasını açın.
2) İçindeki tüm dosyaları GitHub reposunun ana klasörüne yükleyin.
3) GitHub > Repository > Settings > Pages bölümüne girin.
4) Source: Deploy from a branch seçin.
5) Branch: main, Folder: /root seçip Save yapın.
6) Custom domain alanında demiryolcu.com.tr yazılı olduğundan emin olun.
7) DNS tarafında GitHub Pages A kayıtları ve www CNAME kaydı doğru olmalıdır.

CNAME dosyası içinde sadece şu satır vardır:
demiryolcu.com.tr
